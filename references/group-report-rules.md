# 小组 / 组会汇报规则（scenario: report）

## 结构（8-20 页）

1. `cover` — 题目、组员、日期
2. `bullets` — 本次汇报要解决的 1 个问题（只说 1 个）
3. `section` — 背景 / 方法 / 结果 / 讨论（按需取 2-3 个章节页）
4. `bullets` — 每页一个论点，标题是论点本身
5. `kpi` — 实验结果或核心指标，3-4 个
6. `closing` — 结论 + 待讨论问题

## 纪律

- **单页单主题**：一页出现两个并列论点就拆页
- **留白优先**：正文字号 ≥ 24pt，宁可少写也不缩小
- **风格全页一致**：不混用多套版式，章节页只在切换大板块时出现
- 文献引用写在 `notes` 里，不占正文
- 结论页必须给出"下一步做什么"
